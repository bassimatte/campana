What is Campana?

Campana is a generative bell synthesizer that creates endlessly evolving, looping bell soundscapes directly in your browser. Each preset is a living composition — never exactly the same twice.

Sound Engine

Every bell tone is built from scratch using additive synthesis: a set of inharmonic partial frequencies characteristic of real bells are summed and shaped with individual amplitude envelopes. Four textures model different bell families:

  • Tubular — steel tube bells, bright attack
  • Church — cast bronze, deep fundamental
  • Bowl — Tibetan singing bowls, slowly beating partials
  • Crystal — glass harmonics, high shimmer

Effects Chain

  • Freeverb — algorithmic reverb (comb + allpass filters) for spatial depth
  • Stereo delay — ping-pong echo with adjustable time and feedback
  • Time scatter — detaches notes from the strict grid for a free, floating feel
  • Humanize — micro-variations in timing and velocity
  • Beating — slight detuning between partials, simulating the slow pulsations of real bells

Presets

  • Sera — Dusk church bells in D minor. Rich, warm strikes with deep reverb.
  • Tempio — Tibetan singing bowls in G dorian. Slow, beating partials that shimmer and breathe.
  • Cristallo — Crystal glass harmonics in B♭ pentatonic. Airy shimmer and scattered timing.
  • Cattedrale — Cathedral tolls in D minor. The heaviest reverb, slowest pace, widest stereo field.
  • Deriva — Floating, untethered bells in E♭ minor. Maximum scatter — notes drift freely off the grid.
  • Notte — Dark, low-register bells in F minor. Sparse and contemplative, ideal for late hours.
  • Festa — Bright C major arpeggios at 90 BPM. Joyful tubular bells with a jubilant high-register finale.
  • Aurora — Whole-tone scale ascending and descending arc in D. Dreamy, ambiguous harmony with shimmer.

Architecture

Audio is rendered server-side in Python (NumPy + SciPy) and streamed to the browser as WAV chunks via a FastAPI backend. The Web Audio API plays chunks gaplessly using a two-chunk prefetch strategy.
